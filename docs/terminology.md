# GIL 实现术语与边界

## 语义与执行

- 规约：定义允许的可观察行为；不是执行授权。
- AST：语法的结构化表示；规范化 AST 是内容引用对象。
- 解释：自然语言输入的候选形式化理解；概率高不等于被接受。
- 目标：必须实现的结果；开放轨迹尚未达到目标不等于已违规。
- 硬约束：可接受行为不得违反的条件；Unknown 不算满足。
- 偏好：在可接受行为之间排序；不能扩大允许集合。
- 动作契约：环境前置、后置和写集；角色许可属于外层。
- 帧条件：未声明可写的规约内状态不变化；不隐藏外部效果。
- 模拟：在合成状态上检查或产生候选后状态；不表示现实执行。

## 信息状态

- 缺失事实：有足够检查范围，确认某条记录不存在。
- Unknown：当前信息不能确定真值；不表示确定缺失。
- open：显式待定参数；不授权系统任取值。
- ambiguous：多个形式化候选；不是概率分布，也不是第四种真值。
- disputed：断言受到争议；不是直接判假。
- Option：领域值允许不存在；不是未知或歧义。
- ill-formed：语法、类型或引用不合法；不能进入正常求值。
- unsupported：当前实现未支持；不能悄悄当作合法且满足。

## 协作与保障

- Accept：有权主体接受精确内容及范围；不授予行动权限。
- Grant：动作、对象、范围和条件内的权限；默认拒绝。
- Approval：对具体行动计划的批准；实质变化后不自动继承。
- VerificationPlan：准备如何检查；不是通过结论。
- Attestation：特定目标、上下文、版本和覆盖范围内的凭证。
- Restore：恢复定义的先前状态；Compensate 仅补偿，不保证完整恢复。

## 临床切片

- 发现关闭：CTM 按当前有效证据与授权记录完成处置；不等于历史偏差从未发生。
- 培训记录检查：对指定人员和适用要求版本的材料检查；不单凭上传证明培训真实性。
- 适用要求：有明确作用域、政策来源及版本的要求；不默认采用“最新”。
- CAPA：本切片不自动将每次整改升级为正式 CAPA，也不替组织作出此判断。
