# 标注术语表（1 页）

本表只解释字段含义，**不提供判断规则**。请按你自己的理解作答；本任务没有标准答案，目的是检验材料能否被不同的人读成同一个意思。

## 一、你要回答的两个问题

对每个案例，判断：

1. **truth**：这条主张是否成立？三选一。
2. **observation**：这次观察属于哪种情况？四选一。

## 二、观察字段

| 字段 | 取值 | 含义 |
|---|---|---|
| `readability` | `Available` | 来源内容可以正常读取 |
| | `Partial` | 只能读取一部分 |
| | `Unavailable` | 读不到（损坏、权限不足、未导出等） |
| `completeness` | `Complete` | 对该范围内的全部对象都做过检索 |
| | `Partial` | 只检索了部分对象 |
| | `Unknown` | 无法确定检索覆盖了多少 |
| `searched` | `true` / `false` | 是否真的执行过检索 |
| `matches` | 非负整数 | 命中的记录条数 |
| `mappingValid` | `true` / `false` | 字段映射是否可信（例如"已入组"确实对应已入组） |
| `applicable` | `true` / `false` | 该要求本身是否适用于这个对象或时间 |
| `windowMature` | `true` / `false` | 观察窗口是否已经走完并已补齐 |
| `scopeCovered` | `true` / `false` | 搜索范围是否覆盖了目标对象与时间 |
| `watermarkCovered` | `true` / `false` | 数据同步水位是否已覆盖预期时段 |
| `closureBasis` | 字符串 / 空 | 说明"这个范围内的检索已经完成"的依据；空表示没有依据 |
| `conflicts` | 列表 | 存在互相矛盾、尚未裁决的来源 |
| `lineageRoots` | 列表 | 数据来源的根标识。**两个值相同意味着它们来自同一源头** |

## 三、主张字段

| 字段 | 取值 | 含义 |
|---|---|---|
| `kind` | `Descriptive` | 描述"实际是什么" |
| | `Associational` | 描述变量之间的相关 |
| | `Causal` | 声称因果 |
| | `Predictive` | 预测未来 |
| | `Normative` | 规范判断（应该怎样） |
| `fact` | 字符串 | 要判断的事实名。`recordAbsent` 是一个特殊名字，意思是"该记录不存在" |
| `causalDesign` | 字符串 / 空 | 因果识别设计；空表示未提供 |
| `uncertainty` | `None` / `ScenarioEnvelope` / `ConfidenceInterval` | 不确定性的呈现方式 |
| `uncertaintyMethod` | `None` / `Envelope` / `Statistical` | 算出该不确定性的方法 |
| `requiresIndependentSources` | `true` / `false` | 是否要求两条以上独立来源 |
| 事实取值 | 见各案例 | 快照中每个事实的当前值 |

## 四、回答取值

**truth**

| 取值 | 含义 |
|---|---|
| `True` | 主张成立 |
| `False` | 主张不成立 |
| `Unknown` | 现有信息不足以判断 |

**observation**

| 取值 | 含义 |
|---|---|
| `Observed` | 在该范围内确实观察到相关记录 |
| `ConfirmedAbsent` | 可以确认该范围内**不存在** |
| `NotObserved` | 检索过，但不足以确认不存在 |
| `UnableToDetermine` | 无法判断（读不到、范围不清、存在冲突等） |

## 五、几条提醒

- **`Unknown` 是一个正常答案**，不是"我不会"。信息不足时选它，不要勉强猜 True 或 False。
- 判断以案例给出的字段为准，**不要推测未给出的信息**。
- 三个人的答案会各自独立计算，**请不要互相讨论**。
- 完成后请把答案填进随附的 CSV，不要修改案例文件。
