# Phase4：验证凭证、失效与恢复

状态：待用户决定启动。

## 目标

把Phase3中的调用者提供有效性Bool，替换为模拟审核适配器签发的精确凭证投影；证据或要求变化后可靠失效，并支持挑战及授权重开。

## 步骤

1. 建立不可变证据快照与要求工件、摘要和作用域核对。
2. 定义Attestation：spec/target/context哈希、审核者、方法版本、覆盖、期限、Pass/Fail/Unknown。
3. 由独立CRA审核适配器签发，不接受上传者自报真实性作为通过。
4. 建立输入依赖与失效投影，授权门只加载当前有效凭证。
5. 实现复核过期或撤销时的降级、阻断；关闭后挑战及CTM授权重开，保留历史。
6. 集成CLI与验收案例A05–A15/A18/A27–A29相关部分；整理全部A01–A30覆盖矩阵。

## 验收

- 无凭证、Unknown、过期、撤销及版本不匹配不能复核通过或关闭。
- 调用者勾选authenticityEstablished/reviewStillValid不能绕过适配器。
- 替换证据或要求后旧凭证与关闭批准失效。
- CLOSED后挑战不覆盖历史；当前有效状态经受权动作重开。
- 原100项测试不回退；新增有明确输入/结果的负例。

## 边界

仍为合成数据与模拟身份；人类审核结论不是材料真实性的普遍证明或监管认证。不接真实系统、不做医疗判断。不包含生产认证、持久化或跨进程事务。
